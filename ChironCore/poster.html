ABSTRACT

Chiron-Slice is a full-featured program analysis and visual debugging framework for Chiron Turtle-Lang. Building on Milestone 1's Data Dependence Graph (DDG) via Reaching Definitions DFA (including implicit visual states such as :__pen_color, :__pen_status, :__heading, :__position), we implemented a Control Dependence Graph (CDG) using Post-Dominator Trees on the reversed CFG and fused both into a Program Dependence Graph (PDG). This enables mathematically precise backward slicing, forward taint analysis, semantic color extraction, visual dead-code detection, and a fully interactive HTML dashboard that lets users click any turtle stroke on the canvas to instantly see the responsible source-code slice.

THE PROBLEM
  • • Traditional debuggers cannot trace visual output back to source code
  • • Geometric and drawing bugs are extremely difficult to localize
  • • Static slicers are blind to implicit graphical state (color, pen, heading)
  • • No direct mapping between canvas strokes and original .tl lines
  • • Dynamic loop unrolling and runtime behavior are invisible in static analysis
WHY THIS PROJECT IS COOL
  • • First system that directly links ink on screen ↔ original source code
  • • Interactive browser dashboard: click any stroke → exact slice appears
  • • Semantic color-based sub-program extraction
  • • Visual dead-code detection (pen-up moves, unused math)
  • • Full PDG implementation following Ottenstein & Ottenstein (1984)
  • • Real-world debugging power for complex turtle drawings
